Windows PowerShell:
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe crawler.py
.\.venv\Scripts\python.exe crawler.py --help
.\.venv\Scripts\python.exe crawler.py --discover
.\.venv\Scripts\python.exe crawler.py --recursive
.\.venv\Scripts\python.exe -m unittest discover -s tests -v

Linux/macOS:
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python crawler.py

Optional background session on Linux:
tmux new -s spo-crawler
tmux ls
tmux attach -t spo-crawler
